# Spec：盘口改造 + 齿轮设置入口 + 训练长度固定 300

## 目标
对桌面版 `kline-training.html` 与手机版 `kline-mobile.html` 同步执行：
1. 删除盘口下方「横向筹码摘要」。
2. 盘口数据新增 市值、流通市值、换手率、外盘、内盘（市值/流通市值/换手率用 iFinD 真实股本，外盘/内盘估算）。
3. 主页设置入口改为右上角齿轮图标。
4. 删除「训练长度」选择，固定 300 根；训练可随时退出。

## 数据可行性（约束）
`kline-data.js` 的每根 bar 仅含 `d/o/h/l/c/v`（`STEP=22`，无股本、无成交额）。股本改为真实数据：

- 新增 `kline-fundamentals.js`：`window.KLINE_SHARES = { 代码: [总股本(股), 流通A股(股)] }`，共 455 条，数据来源同花顺 iFinD（取数日 2026-11-09）。
- 换手率 `turn = v(手) × 100 ÷ 流通A股 × 100`（%）；总市值 `cap = 总股本 × c`；流通市值 `floatCap = 流通A股 × c`。
- 校验：601398 于 2026-11-06 换手 0.1792%，与 iFinD 完全一致。
- 缺股本时（ETF 21 只、603056 德邦股份、601989 中国重工）退化为估算：`floatHands = median(近 60 根 v) / 0.02`，显示加 `≈`。
- 外盘/内盘仍为估算（iFinD 日频无全量主动买卖），固定加 `≈`。
- 外盘 `buy = v * clamp((c-l)/(h-l), 0.08, 0.92)`；内盘 `sell = v - buy`（按收盘位置推断主动买卖，单位：手，两端留 8% 下限避免出现 0）
- 格式化 `fmtCap`：≥1万亿显示「X.XX万亿」，≥1亿显示「X.XX亿」，≥1万显示「X.XX万」
- 外盘/内盘复用现有 `fmtVol`（万手/亿手）
- 估算值统一加 `≈` 前缀，避免与真实盘口混淆（真实股本时市值/流通值/换手不加前缀）
